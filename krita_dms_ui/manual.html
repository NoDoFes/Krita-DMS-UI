DMS Modern UI for Krita

给 Krita 换一套跟着 DankMaterialShell / matugen 走的 Material You 风格界面：圆角、低对比度、动态配色和菜单动画。

说明：这是一个新人用 AI 辅助（vibecoding）慢慢改出来的业余项目，不是专业作品。能用，但可能有 bug，结构也不算漂亮。

兼容性说明

主要在 Krita 6.x / Linux 上测试。代码保留了 PyQt5 兼容分支，但 Krita 5 没有充分测试。

项目关系

Krita UI Redesign（2020，Kapyia & Pedro Reis）
        ↓
Krita-MorandiUI（LanRhyme）
        ↓
Krita-DMS-UI / DMS Modern UI（本项目）

本项目很大程度上参照了 Krita-MorandiUI；配色另外接的是 DankMaterialShell / matugen 的动态调色板（这是配色来源，不是上游项目）。三个 UI 项目都按 GPL-3.0 分发。

包含的内容

  1. DMS Modern UI 插件: krita_dms_ui
  2. SVG 图标素材: krita_dms_ui/assets/icons
  3. 说明文档: manual.html、README.md

主要功能

  • 跟随 Krita / matugen / DankMaterialShell 的调色板自动取色
  • 菜单、工具栏、面板、输入框、滚动条统一圆角
  • M3 状态层和自绘勾选控件
  • 菜单、子菜单、右键菜单、ComboBox、tooltip 淡入淡出
  • 换壁纸后监听 .colors 热重载配色，不用重启 Krita
  • 欢迎页整理、SpinBox 箭头 SVG、菜单栏左对齐
  • DMS UI 菜单：菜单显隐、隐藏快捷键提示、动画开关

使用前的注意

  • 不要和 Krita-MorandiUI、Style Sheet Loader 等其他 UI 插件同时开启
  • 部分 Krita 自己绘制的控件无法通过 QSS 修改
  • 切 Krita 样式后勾选控件可能异常，需要重启确认
